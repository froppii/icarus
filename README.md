# icarus
a retro vhs player themed mp3 player, complete with tactile switches and a fun volume button

<img src="Screenshot 2026-07-13 105010.png" width="600">


## why?
ive always wanted a dedicated mp3 player so i can listen to music separately without draining my phone battery too quickly, aswell as not having to use spotify. im also learning more on how to make pcbs and 3d model case from this!

## parts and features
**parts**:
- mcu: esp32 s3 wroom 1
- dac: TAD5212IRGER
- display: ili9431
- power: 3.7V 2000mAh lipo battery
- pcb: 4 layers

**features**:
- 3.5mm headphone jack
- 2.8 inch display
- full sized sd card + 1-bit sdmmc audio streaming
- 5 tactile switches and a rotary encoder
- bluetooth 5.0
- programmable eq
